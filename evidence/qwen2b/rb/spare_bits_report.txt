CAVEAT — a row can pass VACUOUSLY.  'never set' is evidence only
where the field is actually exercised: an opcode with 0 records, or
a CSR offset never written by any scanned stream, trivially reports
every bit free.  Check the record count beside each opcode before
leaning on its row.  The layer SPTR CSR (0x14) is the one home in
the table with NO in-stream writer today — the movers program SPTR
over AXI-Lite, not through a CSRWR record — so its row is vacuous:
SPTR's back-compatibility rests on it being a HOST-written CSR whose
bit 14 the old RTL simply ignored, not on this scan.

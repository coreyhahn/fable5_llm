== Notes / surprises ==
- "Leaf" = IS_PRIMITIVE cells with a non-empty LOC. This gives 776,574 cells, more than
  the ~650k estimate because LUT6_2 pairs, SRL/LUTRAM sub-cells, CARRY8, F7/F8 muxes etc.
  are separate primitives. 8,216 primitives have no LOC: 4,299 VCC, 3,885 GND and
  32 OBUFTDS_DUAL_BUF (DDR4 differential output macros; probably absorbed into
  their HPIOB/DIFFOUTBUF sites, not verified). None of these were dropped from used sites.
- The LUT* leaf-cell counts are not comparable 1:1 with the report's "Total LUTs". The
  report counts physical LUT sites, where a LUT6_2 counts once and LUTRAM/SRL count
  as LUTs. Path matching is exact, so the cross-check is the instance path.
- SITE_TYPE on a used site reports the type it is placed as (e.g. RAMB36 for 245 sites,
  RAMB180 for 11), and unused sites report the primary type (RAMBFIFO36/RAMBFIFO18/RAMB181).
  All of these are BRAM.
- Categorisation choices: IO = BITSLICE_*, HPIOB*, HPIOBDIFF*, HPIO_VREF_SITE, RIU_OR,
  XIPHY_FEEDTHROUGH. GT = GTYE4_CHANNEL/COMMON, PCIE40E4, plus CMACE4 and ILKNE4 (the
  other hard blocks in the transceiver/PCIe area). CLK = BUFG* (including BUFG_GT and
  BUFG_GT_SYNC), BUFCE_*, MMCM, PLL, PLL_SELECT_SITE (PLL* rule, although it is in the
  XIPHY column). OTHER = LAGUNA (2 used: SLR-crossing registers), CONFIG_SITE (1 used,
  owned by block 0 'other'; probably the debug hub BSCAN, not verified), BIAS, HARD_SYNC, SYSMONE4, CFGIO_SITE.
- The GT "columns" list includes the CMAC/ILKN/PCIE column x values (312, 3544) as well as the
  GTY columns (0, 3840).
- 11,894 used sites (17%) hold cells from more than one block. They are mostly CLBs in the
  layer_0 cluster (dn_step / layer_rest / state_dma) and at seams between interconnect and
  DDR/mvchan logic. Owner = the block with the most cells in the site (ties go to the
  lowest non-zero id).
- pitch: the spec-literal medians of distinct-Y gaps for DSP/BRAM/URAM are 1, because those
  sites come in Y/Y+1 pairs inside a column (DSP gaps 1,9; BRAM 1,8; URAM 1,27-31). I added
  pitch.<T>.dy_mean = the mean within-column spacing, ignoring gaps over 64 (holes). Use
  this as the drawn site height: CLB 2.068, DSP 5.162, BRAM 3.44, URAM 7.678.
- No RPM value was negative or above uint16 (extent x 0..3840, y 2..1863).
- smc_ch3 owns 2 OTHER sites (LAGUNA): it is the one block that crosses SLR1->SLR2.
- The xdma_0 PCIe hard block (PCIE40E4_X1Y2) is at RPM_X 3544 and its 8 GTY channels +
  2 COMMONs (X1Y28-35) are on the right edge at RPM_X 3840, all in SLR1.
  DIMMs: ddr4_0 (SLR0) and ddr4_2 (SLR1) use the left-centre I/O column at RPM_X 1320-1323;
  ddr4_1 (SLR1) and ddr4_3 (SLR2) use the right-centre I/O column at RPM_X 2576-2579.
